# Задача
Перевод растровых данных в векторные.

Состав:
тестовое задание
файл с данными (карта)

Состав файла с данными, далее карта.

Протокол хранение данных в карте:
uint32_t w - ширина карты
uint32_t h - высота карты
uchar* data - данные

Ячейки данных могу хранить следующие значения:
0 - пустота
1 - данные дома
2 - данные станции

Сущность пустота - излишняя информация, которую не надо переодить в векторный вид.
Сущность дом - имеет прямоугольную форму. В карте сущность дом представлена в виде ячеек со значение 1. Количество ячеек по ширине и высоте больше трех.
Пример

00000000000000
00111100000000
00111100000000
00111100000000
00111100000000
00000000000000

Каждый отдельный дом имеет вокруг себя поля с нулями, таким образом все дома не пересекаются друг с другом + не стоят рядом с друг другом.

Сущность станция - одна ячейка со значением 2.
Пример:

0000
0020
0000

Каждая станция не стоит рядом с другой станцией или домом.

ЗАДАНИЕ

Написать консольное приложение, которое принимает параметром абсолютный путь к файлу.
Основная задача: перевести бинарные данные карты в векторное пространство.

----------------------------------------------------------

Первая часть.
Программа должна прочитать файл и выдать описание ввида: (формат вывода тегов выбрать самостоятельно)

Дома:
<название> <центральная точка> <размер>
....
<название> <центральная точка> <размер>

Станции:
<название> <центральная точка>

Название для дома и станции сгенерировать самостоятельно. Длина от трех до 8 букв.

----------------------------------------------------------

Вторая часть.

Сформировать структура для хранения, которая будет описывать какие дома подключены к какой станции.
Подключение дома к станции происходит по следующему алгоритму:
1. расчитывает расстояние между координатами станции и центральной точки дома.
2. дом подключается к станции, расстояние которой наименьшее. Если расстояние к двум станциям одинаоковое, то выбирается одна из станций.

----------------------------------------------------------

Третья часть:
Предоставить пользователю вводить запрос в консоле:
1. По введенному названию станции получать список домов, которые подключены к этой станции в порядке от ближайшего к дальнему.
Формат вывода:

<название>: <название дома>(<пиксельное расстояние>), ....

Пример:
STAT1: H1(43), H4(52), H7(222)
